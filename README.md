## Project Overview

This project is a responsive personal portfolio website developed as part of the AUREX Full-Stack Engineering Internship — Month 1, Week 2.

The Week 2 task focused on applying CSS3 styling and modern layout techniques to the HTML portfolio webpage created during Week 1. The website was designed to have a clean, professional, user-friendly, and responsive interface.

## CSS Features Implemented

### 1. CSS3 Styling

The website uses CSS3 to improve the visual appearance and user experience. The following features were implemented:

* CSS selectors
* CSS variables
* Colors and backgrounds
* Typography and text styling
* Borders and border-radius
* Shadows
* Hover effects
* Transitions
* Gradients

### 2. CSS Box Model

The CSS Box Model was applied throughout the website using:

* Width and height
* Padding
* Margin
* Borders
* `box-sizing: border-box`

This helped maintain consistent spacing and proper alignment between different elements.

### 3. Flexbox

Flexbox was used for modern page alignment and layout, including:

* Header content alignment
* Navigation menu
* Contact form layout
* Horizontal and vertical alignment
* Spacing using `gap`

### 4. CSS Grid

CSS Grid was used to create structured layouts, especially for the Skills section.

The skills are displayed in:

* 3 columns on desktop
* 2 columns on tablet
* 1 column on mobile

This makes the layout flexible and responsive.

### 5. Responsive Web Design

Media queries were implemented to make the website responsive across different screen sizes.

#### Desktop

The website provides a spacious layout with larger typography and multiple-column content.

#### Tablet

The layout adjusts the navigation, typography, spacing, and skills grid for medium-sized screens.

#### Mobile

The website uses smaller typography, reduced spacing, and a single-column skills layout for smaller screens.
